# TV Player

مشغّل IPTV لأندرويد وأندرويد TV (Kotlin + ExoPlayer / Media3).

## شو بيدعم

| نوع السيرفر | شو بتحط |
|---|---|
| **Xtream Codes** | رابط السيرفر + اسم المستخدم + كلمة المرور. أو الصق رابط `get.php?username=..&password=..` كامل وهو بيطلّع البيانات لحاله |
| **M3U / M3U8** | رابط القائمة. بيقرأ `group-title` و`tvg-logo` و`#EXTGRP` و`#EXTVLCOPT` وهيدرات كودي `url\|User-Agent=..` |
| **رابط مباشر** | أي رابط بث: HLS (m3u8)، DASH (mpd)، TS، MP4/MKV، RTSP |

### المميزات
**التنقل والترتيب**
- تبويبات: البث المباشر / الأفلام / المسلسلات، وتحت كل وحدة **نفس تصنيفات السيرفر** وبنفس ترتيبه
- **بحث شامل** بكل السيرفر مرة وحدة (قنوات + أفلام + مسلسلات) مع فلتر حسب النوع
- ترتيب: ترتيب السيرفر / الأحدث إضافة / الاسم / الأعلى تقييماً / الأحدث سنةً
- صفحة تفاصيل للفيلم والمسلسل: البوستر، القصة، التصنيف، التقييم، السنة، المدة، الإخراج والممثلين
- المسلسلات مقسّمة على مواسم، وكل موسم بحلقاته

**قوائمك**
- ▶ **متابعة المشاهدة**: بيحفظ وين وقفت بالفيلم أو الحلقة وبيرجع يكمّل منها. إذا خلصت حلقة بيحط الحلقة الجاية مكانها
- ضغطة مطوّلة على أي عنصر ← **إزالة من متابعة المشاهدة** (وبيختفي)، أو إضافة / إزالة من المفضلة
- ⭐ **المفضلة** و🕘 **آخر القنوات** اللي حضرتها

**أثناء المشاهدة (⚙ الإعدادات أو زر Menu بالريموت)**
- **الجودة**: تلقائي، أو حد أقصى (4K / 1080p / 720p / 480p / 360p) وبيتذكّره، أو جودة معيّنة من الجودات اللي بيبعتها السيرفر. إذا السيرفر بيبعت جودة وحدة بس، التطبيق بيحكيلك شو هي
- **الترجمة**: اختيار الترجمة أو إيقافها (العربي بينختار تلقائياً إذا موجود) + **حجم الترجمة**
- **الصوت**: اختيار مسار الصوت / اللغة
- **حجم الشاشة**: ملاءمة / تكبير / تمديد
- **سرعة التشغيل** للأفلام والحلقات
- ☰ **قائمة الحلقات** وأنت بتحضر: بتشوف كل الحلقات (والحلقة الحالية معلّمة) وبتنتقل لأي وحدة. بالبث المباشر نفس الإشي بس للقنوات
- الحلقة الجاية بتشتغل تلقائياً

**التشغيل**
- محاولات تشغيل متعددة: إذا الرابط ما إله امتداد بيجرّبه عادي وبعدين كـ HLS، وبيبدّل بين `.m3u8` و`.ts` بقنوات Xtream
- بيعيد الاتصال تلقائياً إذا انقطع البث
- User-Agent افتراضي تبع VLC، وبتقدر تغيّره لكل سيرفر

### الريموت
| الزر | الوظيفة |
|---|---|
| ▲ ▼ أو CH+ / CH- | القناة الجاية / السابقة (بالبث المباشر) |
| OK | بالبث المباشر: قائمة القنوات • بالأفلام: أزرار التحكم |

| Back | بيسكّر القائمة، وبعدين بيطلع |

## طريقة البناء

### الطريقة 1: Android Studio
1. افتح مجلد `TVPlayer` بـ Android Studio (Ladybug أو أحدث)
2. استنى الـ Gradle Sync يخلص
3. **Run ▶** على الجهاز أو المحاكي، أو **Build → Build APK(s)**

### الطريقة 2: GitHub (بدون ما تنزّل إشي)
1. اعمل repo جديد على GitHub وارفع عليه ملفات المشروع
2. البناء بيشتغل لحاله (تبويب **Actions**)
3. لما يخلص، افتح الـ run ونزّل ملف **TVPlayer-apk**

### التنصيب على الشاشة / TV Box
- نزّل تطبيق **Downloader** على الشاشة وحط فيه رابط الـ APK، أو
- `adb connect <IP الشاشة>` وبعدين `adb install app-release.apk`

## ملفات المشروع
```
app/src/main/java/com/tvplayer/app/
├── data/
│   ├── Models.kt        البيانات (سيرفر، قناة، تصنيف، تفاصيل)
│   ├── ProfileStore.kt  حفظ السيرفرات، المفضلة، متابعة المشاهدة، الإعدادات
│   ├── Http.kt          اتصال الشبكة (OkHttp)
│   ├── M3uParser.kt     قراءة قوائم M3U
│   └── XtreamApi.kt     واجهة Xtream Codes
└── ui/
    ├── MainActivity.kt       قائمة السيرفرات
    ├── AddServerActivity.kt  إضافة / تعديل سيرفر
    ├── BrowserActivity.kt    التصنيفات والقنوات
    ├── DetailsActivity.kt    تفاصيل الفيلم / المسلسل والمواسم
    ├── SearchActivity.kt     البحث الشامل
    ├── Nav.kt                فتح العناصر وقائمة الضغطة المطوّلة
    ├── PlayerActivity.kt     المشغّل
    └── Adapters.kt
```

> ملاحظة: التطبيق مجرد مشغّل وما فيه أي محتوى. استخدمه مع سيرفرات عندك حق تشغّلها.
